# 🚀 Python Multi-Project Portfolio

Welcome to my Python Developer Repository! This repository showcases a comprehensive collection of projects covering **Web Scraping, Artificial Intelligence, Web Development, Automation, and Desktop Applications**.

## 🛠️ Tech Stack & Skills

- **Languages:** Python, HTML/CSS, SQL
- **Frameworks & Web:** Flask, REST APIs

- **GUI & Automation:** Tkinter, Turtle, `pyttsx3`, `webbrowser`
- **Libraries:** BeautifulSoup, `requests`

---

## 📂 Project Showcase

### 🔍 1. Nexus Search Engine
- **Files:** `crawler.py`, `app.py`
- **Features:** Custom web crawler that scrapes live websites, indexes pages into SQLite, ranks queries, and serves results via a Tkinter GUI.

### 🌐 2. Flask Web Application & Auth System
- **Files:** `flask_app.py`, `app_with_db.py`
- **Features:** Dynamic web portal using Flask framework, form handling, custom greetings, and user authentication with SQLite persistence.

### 📈 3. Live Crypto Price Tracker
- **File:** `crypto_tracker.py`
- **Features:** Fetches real-time market data for Bitcoin and Ethereum using REST APIs and presents it in a styled desktop GUI.

### 🤖 4. System Automation Assistant
- **File:** `voice_bot.py`
- **Features:** Text and voice-command based system bot to open native applications (Chrome, Notepad) and web services (YouTube, Google) with text-to-speech output.

### 🎮 5. Retro Snake Game Pro
- **File:** `snake_game_pro.py`
- **Features:** Classic desktop game built using Python `turtle` module with collision detection and real-time score updates.
