## 📂 Project Showcase

### 🔍 1. Nexus AI & Web Search Engine (Bharat Search)
- **Files:** `app_with_db.py`, `search_engine.db`
- **Features:** 
  - Dynamic AI Overview answers powered by **Google Gemini API**.
  - Automatic web crawler with favicon metadata extraction & SQLite indexing.
  - Custom SafeSearch filters, Search History tracking, and Google-style UI with interactive mini-games.

### 🌐 2. Flask Web Application & Auth System
- **Files:** `flask_app.py`, `app_with_db.py`
- **Features:** Dynamic web portal using Flask framework, session management, secure user/owner authentication, and SQLite persistence.

### 📈 3. Live Crypto Price Tracker
- **File:** `crypto_tracker.py`
- **Features:** Fetches real-time market data for Bitcoin and Ethereum using CoinGecko REST APIs and presents it in a styled desktop GUI.

### 🤖 4. System Automation Assistant
- **File:** `voice_bot.py`
- **Features:** Text and voice-command based system bot to open native applications (Chrome, Notepad) and web services (YouTube, Google) with offline text-to-speech output.

### 🎮 5. Retro Snake Game Pro
- **File:** `snake_game_pro.py`
- **Features:** Classic desktop game built using Python `turtle` module with collision detection, high score tracking, and smooth controls.
